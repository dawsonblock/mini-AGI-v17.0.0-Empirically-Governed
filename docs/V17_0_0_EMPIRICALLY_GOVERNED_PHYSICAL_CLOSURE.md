# mini-AGI v17.0.0 — Empirically Governed Physical Closure

This release is a conservative convergence of the strongest mechanisms in the supplied v16.0.1, v15.5, RC12.4, RC12.5, RC14.5, and governed Dream-RSI artifacts.

## Authority planes

1. Cognitive plane solves tasks and records evidence.
2. Learning plane may propose interventions but has no promotion authority.
3. Qualification plane independently evaluates fresh transfer, retention, falsification, replay-policy evidence, and physical closure.
4. Promotion/serving plane may activate only qualified, content-bound artifacts.

## v17 changes

- Retains v16.0.1 converged governed RSI and least-permanent-first plasticity execution.
- Adds v15.5 physical artifact binding implementation and regression tests to the canonical tree.
- Adds `minagi.v17.physical_closure`, which measures model/tokenizer/runtime/KVMem plus adapter-set, retrieval-policy, and skill-policy bytes, including zero-root semantics.
- Adds `minagi.v17.empirical_gate`, a fail-closed aggregate gate for preregistration, fresh transfer, retention, falsification, replay qualification, live canary, security, physical closure, and independent authority identities.
- Vendors the supplied RC12.4, RC12.5, RC14.5 and governed Dream-RSI source releases under `research_authorities/` as auditable references. They are not silently imported into the serving process.
- Does not claim demonstrated AGI, recursive model self-improvement, or real forward transfer merely because qualification infrastructure exists.

## Required promotion sequence

Experience -> Evidence -> Hypothesis -> Abstraction -> Falsification -> Transfer -> Learning Proposal -> Preregistered Experiment -> Independent Qualification -> Live Canary -> Physical Artifact Closure -> Promotion.

The proposal/learning process must not sign or self-approve its own promotion evidence.
