# RC0-RC12 Roadmap

RC0 Frozen baseline, deterministic harness, base-model hash lock, holdout commitments.
RC1 Evidence quarantine/admission, immutable ledger, provenance closure.
RC2 Versioned beliefs/hypotheses and executable skills.
RC3 Skill graph, compositional skills, deterministic verifiers.
RC4 Experience graph, grounded replay, strict prefix observability, policy Dream Engine.
RC5 Prediction error, counterexample search, information-gain active experimentation.
RC6 Transfer engine, R1-R6 rings, transfer-selective replay, fresh task-family authority.
RC7 Deterministic Plasticity Proposer + capability-gap/CapacityProbe.
RC8 Adapter/module candidates; production base remains frozen.
RC9 Independent qualification, adversarial forgetting search, signed promotion, rollback.
RC10 Model-based imagination for unexplored branches; predictions explicitly untrusted.
RC11 Meta-learned Plasticity Proposer from qualified Improvement Ledger only.
RC12 Controlled shared-weight/architecture proposals through the identical authority chain.

Gate: no RC may create a path from Learning Plane to authoritative persistent state or production execution without qualification/promotion.
