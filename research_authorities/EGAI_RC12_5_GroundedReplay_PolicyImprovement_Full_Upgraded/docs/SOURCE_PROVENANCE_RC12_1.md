# Source Provenance

Built directly from the uploaded source archives: RC11.7 Persistent DataPlane (base), EGAI v3 RC8.2 (governance/frozen-model continual learning), and KVContinual RC10.25 (namespaced target-Mac execution/qualification reference). The RC10.25 package is namespaced instead of overwriting RC11.7 execution code because the two releases contain overlapping but non-identical invariants; this prevents a silent regression during convergence.
