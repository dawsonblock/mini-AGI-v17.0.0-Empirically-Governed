- canonical runtime identity 12.4.0;
- signed experiment preregistration;
- encrypted AES-256-GCM hidden-task vault;
- FreshTaskAuthority one-time candidate-bound hidden-suite lease binding;

- paired bootstrap confidence intervals;

- incremental B0-B5 ablation stop/go protocol;
- RC12.3.1 target-Mac qualification, Apple performance tools and fail-closed HYPIC/Metal authorization retained.

Deliberately not claimed:

- empirical positive forward transfer on a real 1,000-5,000 task stream;
- real target-Mac HYPIC/Metal equivalence unless separately qualified on the target machine;
- automatic adapter promotion;
- learned plasticity authority;
- shared-weight online learning;
- architecture self-modification.

The release provides the machinery for the first defensible frozen-base continual-learning experiment. Real scientific claims require running that experiment on a fixed model and untouched hidden task families.
